# 本机配准测试台

在项目根目录双击 `启动配准测试台.cmd`，或运行：

```powershell
& .\.venv\Scripts\python.exe -B .\visualization\registration_lab\server.py --open
```

默认地址为 `http://127.0.0.1:8766`。端口被占用时加 `--port 8767`。关闭命令窗口或按 Ctrl+C 停止服务。

1. 选择2D图和整板深度图。选择项目编号样本（如006.png）自动填第6片，也可手动改片号；自定义文件不会按名称猜测片号。
2. 默认“不补偿，仅做配准”，直接点“运行配准”。需要在工具中补偿时选择“原始数据：在此补偿”，填写角度与实际扫描步距；已由SDK补偿的输入选择“SDK已补偿：本工具跳过”。
3. 手动路径、已分片深度模式藏在“手动路径 / 深度格式”；图像来源、扫描方向、公式方向、内触发、深度标定、配准阶段和JSON参数均在“高级设置 / 参数管理”。默认按图像行扫描、还原公式、外触发，不自动猜测设备标定。
4. 结果区直接显示本次图片、片号及实际补偿状态。修改输入/参数后提示重新运行，旧结果的状态不会跟随新设置改变。
5. 默认原图+深度彩色叠加；支持透明度、边缘、左右划分和缩放。耗时/矩阵折叠在结果详情。“保存为对照A”后可与下一次结果切换比较。
6. 切换到SmartRay同栅格强度图后，补偿时自动同步映射，不再单独勾选。参数仍可导入导出，旧SmartRay配置可兼容；通用旋转参数或未确认状态的启用配置会关闭并提示重新设置。

## SmartRay Pitch 补偿（默认关闭）

依据用户提供的 SmartRay Studio 4 用户指南 §6.10 截图实现。此处 **X指扫描/输送方向**，Y为轮廓横向，Z为设备标定高度；可选择扫描对应图像行还是列，不把文档X直接当作图像横向。

文档关系：`X′=X+Z*sinβ, Y′=Y, Z′=Z*cosβ`。

- **测量值还原**（界面默认）：若输入为上述X′/Z′，使用 `Z=Z′/cosβ, X=X′-Z′*tanβ`。
- **文档正向**：按截图所列公式直接将X/Z映射为X′/Z′。两种方向显式选择，不假定SDK导出值一定属于其中一侧。
- 本模型没有 `-Y*sinβ` 逐行高度斜坡项，不使用Y/Z旋转中心，不对独立2D照片做 `1/cosβ` 拉伸。
- 文档规定：扫描运动从光学镜头朝向激光方向时角为负，反向为正。需依据实际传感器方向填写；某些型号的出厂安装角不应与额外倾角盲目相加。

### 输入状态与标定

“原始数据：在此补偿”表示用户已确认未做SDK补偿；“SDK已补偿：本工具跳过”会保留原数组、避免双重补偿。后端仍拒绝启用但状态未确认的请求。

外触发填写实际 **扫描步距 mm/profile**。内触发填写扫描速度mm/s与触发频率profile/s，以速度/频率计算基础步距；设备若已有额外几何补偿或非匀速运动，不能把基础步距等同于未经核实的设备输出标定。

深度物理值 `Z=(raw-gray_offset)*z_step_mm+z_origin_mm`。新增的设备Z原点表示灰度零点对应的SmartRay物理Z，不是旋转轴高度。默认0仅是待标定值，必须按实际导出格式/标定确认。深度经过比例补偿后按同一标定编码回uint16。

配置示例（仅演示结构，步距和角度需实际填写）：

```json
{
  "model": "smartray_pitch",
  "enabled_3d": true,
  "enabled_2d": false,
  "input_state": "uncorrected",
  "image_role": "independent_camera",
  "transform_direction": "recover_ideal",
  "scan_axis": "rows",
  "trigger_mode": "external",
  "scan_pitch_mm": 0.01,
  "angle_deg": 6,
  "z_step_mm": 0.00105,
  "gray_offset": 32768,
  "z_origin_mm": 0
}
```

### 2D图像来源与重采样

- **独立相机照片**：保持原图，不套SmartRay公式；由后续配准对齐。可使用现有2D样本。
- **SmartRay同栅格强度图**：必须和输入深度整图尺寸一致、逐像素对应；补偿时自动同步映射强度图。按深度产生的同一位移重采样，碰撞时采用最高Z样本对应的强度，同高时采用较大源索引。不能把不同相机照片仅缩放到相同尺寸就当作同栅格图。
- 强度图整板输入沿深度的相同行范围切片；独立照片仍是单片输入。切换强度图后需按其实际尺寸调整粗配准搜索区与尺度，现有默认参数针对独立高分辨率2D照片。
- 变换不是全局3×3单应矩阵。强度图重采样时导出 `homography_original_2d_to_corrected_depth=null`，只提供补偿后强度图到深度片的配准矩阵。独立照片仍可导出原图到补偿后深度片的矩阵。
- 补偿在整板分片前执行。输出保留原画幅、最近邻前向投影，碰撞取较高Z；0/65535无效点跳过，空洞不填补，越界/超量程点丢弃并记录数量。`depth_rows`为补偿后深度图的行号，不表示原深度坐标。

旧版通用旋转参数不自动迁移为SmartRay参数：界面导入后关闭补偿并要求重新确认；后端拒绝带旧模型的启用请求。测试台协议版本5，旧服务需重启。正式流程现已通过config/3D/config.json的smartray_pitch_3d接入，默认关闭；不修改设备SDK设置。尚未取得设备实际矫正状态、原点/步距和倾斜标定样本，不能宣称与设备内置补偿数值等价。

直接调用生产 `platform_mask_2d/3d`、`register_platform_masks`、`refine_affine_registration`，不加载 YOLO/EfficientAD，也不修改算法或生产配置。测试台同步移除透视求解；仅保留粗配准与仿射。

整板分片严格沿用检测流程的 `depth[y1:y2]`，保留整幅宽度，矩阵映射到深度片局部坐标；转换为整板坐标需加 `depth_rows[0]`。界面输入片号不会自动切换2D图，请自行保证配对。

耗时分开显示配准计算、读图、分片和预览；它们是单片隔离测试结果，不能直接代表生产并发节拍。灰度差值仅供观察，因为2D亮度与深度值不是同一种物理量。有效标记沿用现有算法，应结合配准叠加和实际精度要求验收。

浏览的图像暂存于系统临时目录，关闭服务后清理；结果仅保留在页面内存，刷新会丢失，需提前导出。导出的测试记录包含输入路径和变换/参数/耗时，不包含图像。上传临时路径只对本次服务有效，复测需重新选文件。

仅监听127.0.0.1，不需额外依赖或GPU。验证：

```powershell
& .\.venv\Scripts\python.exe -B -m unittest discover -s visualization/tests -p test_registration_lab.py -v
```

3D伪彩色只用于显示：每片按有效深度的P1～P99归一化，低值偏蓝、高值偏红，0/65535无效像素透明。色阶是当前片的相对深度，不是绝对高度或缺陷等级；A/B颜色范围可能随数据变化，数值比较请以原始深度/测量结果为准。配准依然使用原来的灰度输入。

## 仿射评分区域图层

对齐结果默认显示空心R1/R2/R3框，可通过预览工具栏“评分区域”开关隐藏，不需要重跑。框使用后端算法 `_affine_rois` 返回的实际范围（自定义rois及图像边界裁剪均生效），坐标为深度片局部像素，不叠加2D原图偏移或再乘配准矩阵。显示随缩放/平移，A/B各取保存结果中的范围；未执行仿射时标为参考区域。旧结果未含元数据时会提示重新运行。

默认横向165～520、520～950、950～1380，纵向40～片高减44；评分框是仿射优化区域，不是引线检测ROI。导出结果包含 `affine_scoring`。

## 选择参与仿射评分的区域

预览上方可勾选R1/R2/R3，默认全选，可任意组合但至少选一个。修改后必须重新运行；原结果不会被重新标记为新选择。切换到“仿射配准”阶段查看这次选择的影响。

选择写入 `dynamic_affine_3d.selected_regions`（1起始编号），例如 `[1,2]` 只对R1与R2求平均掩码差异。全部选中时删除该键，保留原有默认行为；空列表、重复编号或无有效范围的编号会被拒绝。自定义rois时编号始终对应原列表，裁剪/无效框不会令编号重排。

结果保留全部参考框，实线表示本次参与、虚线表示未参与；A/B各用自身结果记录。`affine_scoring.selected_region_ids`与`registration.affine_scoring_region_ids`标识实际参与区，`affine_zone_losses`按这些编号顺序返回。较低的局部评分不保证其他区域也更准，单一区域可能缺乏足够的全局约束，应结合整图叠加与已知几何验证。

## 保存并跨片复用矩阵

1. 第一片正常配准后，切到需要保存的阶段（粗配准或仿射），点击“保存当前阶段矩阵”。下载 `registration-matrix-阶段.json`，本页也保留一份可立即复用的副本。
2. 换成第二片的2D图与片号，把“对齐方式”改为“复用已保存矩阵”，运行即可；不再调用粗配准或仿射求解，也不重新计算配准质量分数。相机/定位变化会使复用结果产生偏差，仍须检查叠加。
3. 刷新或重启后，可在复用模式点击“载入矩阵文件”恢复该矩阵。文件包含3×3矩阵、来源阶段/片号、坐标约定和有效Pitch处理上下文；它不是普通参数文件，须通过矩阵入口载入。

矩阵始终映射当前2D输入到深度片局部坐标，不叠加来源片的整板行号，也不会因当前片的起始行不同而改写系数。目标深度片高度可变化（提示裁切/画幅变化），目标宽度须一致。独立2D照片尺寸须一致；同栅格强度图允许分片高度变化但宽度须一致。Pitch处理、图像来源或坐标约定不兼容时拒绝复用，避免系数被错误解释；不会自动修改补偿参数或缩放矩阵。

复用结果只验证矩阵是否可投影，不代表当前片配准质量合格；界面显示“未重新评分”，当前片的质量字段为null，不沿用来源片的匹配分。原始SDK输出本身的校准、安装位置和坐标稳定性还需要使用者确认。

自定义文件上传或手动填写路径后，选择框直接显示原始文件名；服务端临时路径只用于读取，不作为展示名称。切回项目样本仍按编号匹配片号，自定义文件不根据文件名猜片号，手动修改片号后提示同步更新。

透视求解已移除。旧文件若含真正的投影矩阵（底行前两项不为0），复用时拒绝，需重新计算并保存仿射矩阵。
