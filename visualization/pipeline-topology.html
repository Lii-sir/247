预算与提前并发

worker_budget=60，当前五池合计 50。early_joint_workers 未配置，默认等于 joint_workers=10；限制每板 2D 未完成期间尚未完成的提前联合任务数，不是额外的池。

参数优先级与兼容

JSON 优先于对应 BRIDGE_* 环境变量。新增池参数及其环境变量均缺省时，银浆复用后处理池、联合 3D 复用 CPU 池；当前显式配置两个独立池。

并行的实际含义

worker 数是执行槽上限；不保证始终占满，也不等于进程数。CPU 内部库线程、缓存清理线程及请求容量另算。GPU 软件任务重叠不能单凭日志证明 CUDA 内核同时执行。

_measure_piece
透视修正未成功时，配准结果中仍保留初始 H，并标记 perspective_valid=false；不能把“存在矩阵”当成测高有效。当前平台参考面采样路径会检查配准与透视有效性，失败会产生对应诊断。银浆模板点到目标 2D 图的变换与这里的 2D→3D 变换是两套独立配准。

测高采样与参考面

排除对齐语义区域对平台采样的干扰；平台 ROI 由圆定位及配置偏移映射。芯片区域缓存用于减少重复区域计算，测高结果包含有效性与诊断。

thin 的特殊处理

拆为中间引线和两端焊料；两端 solder 再映射并按配置膨胀搜索区域。同一片内部按实际实例处理，不额外创建子线程池。

坐标输出

2D 公开轮廓回到原图；3D 对齐掩码使用局部深度坐标；测高点经 height_points_to_board 转换到整板坐标。绘图时需结合字段的 coordinate_space 与片起始行。

汇合规则、图像生命周期与异常

输入到达顺序不限

2D 可先来，3D 也可先来。缓存由 board_id 隔离；本片 joint_entry 与对应 depth piece 同时存在时才提交联合检测，不需要先等全部 2D。

两个不同完成信号

单片 2D 的 Future 返回完整 results_2d。整板 3D 的 Future 要等全部 2D entry、全部 3D results 和空 inflight；最后再次合并完整 2D 诊断，防止提前 3D 丢掉晚到 NG。

共享内存与浅拷贝

原始 BGR8 路径通过 SharedImage 获取视图，但 crop 会显式 copy，解码与模型输入也可能分配内存。分支共享原图引用，直到读取分支结束且完整后处理退出后释放 owner；不能宣称全链零拷贝。

重复板号片号

同片正在 inflight 或已 claimed 时拒绝重复。已完成但尚未被联合认领的片允许替换，替换前删除旧 entry/joint_entry。新板应使用新 board_id。

失败与回收

2D 失败返回 2d_piece_failed；已认领联合计算时可终止板。深度解码/分片失败终止板；联合异常返回 joint_detection_failed。release_board、服务关闭也会结束等待的板 Future。

等待与超时

没有正在执行的 2D、深度准备或未完成已认领任务时，闲置缓存才可按 board timeout 过期；不是强制中断正在运行的算法。持续只送 2D 时应主动管理未配对板缓存。

银浆回退只适用于已具备有效标定、匹配失败且 fallback_to_template_points=true 的路径；无效/缺失标定不会自动视为通过。回退直接使用模板点坐标，不能等价于已成功完成目标图配准；边界可超出检测 ROI，诊断与可视化需保留其坐标关系。
