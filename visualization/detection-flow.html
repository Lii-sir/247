测高不是直接读一个灰度值

  1. 将标定的平台 ROI 经当前片配准映射到深度切片。
  2. 排除完整语义掩码及无效深度，拟合平台参考面；各芯片单独拟合芯片面。
  3. 按对象类型选择测量区域与参考面。thin 分出两端焊脚；wire/thin 参与引线测量；bond 参与焊点测量。
  4. 选取配置高度百分位对应的代表像素，换算毫米高度，再减去同位置参考面高度。
  5. 按对应阈值判断，保留 IsValid / IsOk；无效测量不变成“0 mm”。
height_mm = (depth_gray − gray_offset) × vertical_resolution_mm
height_diff_mm = height_mm − 同位置参考平面的毫米高度

参考面、3D 轮廓保持局部坐标；公开测高点转成整板深度坐标。

依据：python/algorithm/detect_board.py::_measure_piece；height_measurement.py::measure_mask_height / height_points_to_board

state.depth 已就绪
且 state.entries 中存在 piece_id
且本片尚未 claimed

claimed 防止同片重复调度。匹配是事件触发，不是让一个 CPU 线程一直阻塞等待。

并行与顺序边界

  • 各片解码、ROI 与后处理可以重叠。
  • 当前片只有预处理完成，才能进入 GPU 队列。
  • GPU 线程完成 YOLO 和 EfficientAD 后，该片才进入 CPU 后处理。
  • 后处理完成后，该片才具备联合测量输入。
  • 整板响应等待十片联合结果全部完成。

银浆：共享标定，逐图配准

所有目标图使用同一个模板和 template_points；每张图计算自己的变换，不能复用上一张图的映射边界。

模板坐标 → 当前目标原图坐标

① 验证真实标定

读取 silver_boundary.json 和模板图。检查尺寸、SHA-256、点数、点序、面积与自交。模板不符或标定非法不以回退掩盖。

② 提取图像特征并估计矩阵

模板/目标灰度与缩放 → SIFT → FLANN → 比率筛选与去重 → RANSAC → 内点数与比例校验 → 投影边界点。

SIFT 只用于求变换，人工标定顶点才是银浆允许边界。模板灰度与 SIFT 特征按内容和参数缓存并在使用时校验；每张目标图仍独立提取特征、匹配并估计自己的矩阵。

业务边界与检测 ROI 是两个区域

保持完整边界，不把点裁到 ROI 上；仅对 ROI 内已分割到的银浆计算边界距离。ROI 外未检测区域不能据此保证无缺陷。

配准有效

映射 template_points

target_points = H(template_points)
Registration.Method = "sift_ransac"
Registration.Status = "ok"
Registration.FallbackUsed = false

边界点先转换成 crop 局部坐标用于测量；对外返回时再转回目标原图坐标。

匹配失败 / 变换不可靠，且开启回退

直接用 template_points

target_points = template_points
Registration.Method = "template_points_fallback"
Registration.Status = "fallback"
Registration.IsValid = false
Registration.FallbackUsed = true

不缩放、不平移点集。模板与目标的位置变化时回退边界不会跟随；匹配尝试的耗时已经发生。

③ 依据允许边界检测银浆溢出

合并银浆 mask → 对银浆像素求有符号边界距离 → 外侧像素 → 距离容差 → 连通区域最小面积筛选 → defect_area_px / defect_contours → OK 或 overflow。

银浆连通另行执行：芯片外环带 → 排除/计入遮挡 → 分扇区评估覆盖 → 缺失扇区 → disconnected / ok / uncertain。

边界回退状态与产品缺陷状态分开：fallback 并不自动表示产品 NG；越界判定仍由实际银浆像素决定。没有标定、没有银浆或无法测量，也不能显示为 OK。

图像数据如何传输

  • 文件接口：C# 读字节、创建共享内存、写入；Python 解码成数组。
  • 原始 BGR 布局接口：传共享内存名、宽高、stride、offset，Python 可建立只读浅引用视图。
  • ROI 会拷贝给模型；算法仍会产生灰度图、掩码及对齐数组，不能说整条流程完全零拷贝。
  • 单片处理结束释放输入引用；为联合处理保留灰度图、掩码、圆/ROI、检查结果。
PythonBridge.cs::DetectPieceSharedMemoryLayout；detect_board.py::prepare_2d_piece / release_prepared_2d

结果和资源是两条生命周期

  • ReleaseBoard(boardId)：清理某板缓存，解除该板等待。
  • 整板正常完成：自动结束该板，不卸载模型。
  • Release / Dispose：结束服务生命周期并释放模型资源。
  • 仍有挂起板/请求时不能随意重新初始化模型。
  • 测试脚本普通单次运行会创建新服务；--repeat 在一次运行中复用服务。

异常分支

触发条件处理上位机含义
2D 解码 / 推理失败返回 2d_piece_failed，释放当前输入。组合上位机调用会释放本板并结束等待。Ok=false 或调用异常，不能作为产品正常检测结果。
3D 分片数不是十片结束本板，返回 3d_board_failed。输入/分片错误，应检查深度图与配置。
同板同片重复或非法片号请求被拒绝；合法片号来自配置范围。检查板号/片号管理，不用返回顺序配对。
联合配准 / 测量抛出异常本板返回 joint_detection_failed；有些测量失败在内部形成 IsValid=false。区分请求故障和无效测量，不能显示 0 mm。
缺少匹配输入且板闲置超时无活跃任务时执行 board_timeout，返回 missing_piece_ids，清理板缓存。板 TTL 不等于活跃计算的硬时限。
客户端请求超时 / 进程断开C# 调用可能抛 TimeoutException 或通信异常。需异常处理；并非所有故障都有 DetectResponse。
产品任一检查 NG正常返回 Ok=true，业务 IsOk=false。显示 NG，不把它误报成通信失败；可以继续检测下一板。

上位机收到什么，如何核对耗时

以当前 Bridge DTO 为准。最终联合结果与单片 2D 返回对象不同。

单片完成

DetectResponse.Results2D

  • BoardId / PieceId：绑定当前原图。
  • Instances / Mask2D：分割轮廓、类别、置信度。
  • Circle / CropBox / WireRois2D：定位及检测范围。
  • WireBending2D / ChipRotation2D / ChipAnomaly2D。
  • SilverOverflow / SilverContinuity2D：边界、回退、缺陷。
  • CacheState：本板已完成缓存的片数与片号。
  • Timings：预处理、GPU、后处理及队列明细。
十片联合全部完成

DetectResponse.ResultsBoard

  • IsOk / RegistrationOk：整板结论与配准有效性。
  • Pieces：按片号排序的联合结果。
  • Mask2D / Mask3DLocal：原图和本片深度轮廓。
  • WireMeasurements / SolderMeasurements：参考面、高度差、测量点。
  • 缓存的银浆诊断和芯片外观结果。
  • 每片 Timings + 整板 Timings。
  • Released：本板缓存清理状态。
Board.DetectStreamingFilesAsync 成功时只返回最终整板响应，不自动嵌入十条 Results2D 响应。需要圆定位、芯片旋转角或单片即时界面时，应保留逐片 2D 接口返回值。

WireRois2D：检测 crop 局部
Mask3DLocal：本片深度局部

模型执行与缺陷状态

response.Ok       → 请求是否执行成功
board.IsOk        → 产品是否合格
height.IsValid    → 测量是否有效
silver.IsOk       → 实际银浆检查结论
FallbackUsed      → 边界来源是否为回退

它们不是同一个判定。空对象、null 或字段缺失不能转成“通过”。
