# Anomalib EfficientAD 2.2.0

This folder is a working copy of the EfficientAD implementation shipped with
`anomalib==2.2.0` in this project's virtual environment.

Copied source files:

- `torch_model.py`: PyTorch network, losses, and anomaly-map computation.
- `lightning_model.py`: Lightning training module and data preparation.
- `__init__.py`: package export.
- `README.md`: upstream module documentation.

The files were copied from
`.venv/Lib/site-packages/anomalib/models/image/efficient_ad/` on 2026-09-18.
The copied Python files retain their original imports and can be modified here
without changing the installed Anomalib package.
